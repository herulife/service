# Design Taste — frontend

Framework-agnostic taste dials. Tune per surface, keep consistent within a product.

- VARIANCE (layout): prefer intentional asymmetry and rhythm over dead-center symmetry.
- MOTION: subtle hover/transition only; no bounce. Respect prefers-reduced-motion.
- DENSITY: enough info per viewport; avoid both empty and cluttered.

## Principles (specificity over decoration)
- Hierarchy before decoration. One clear focal point per section.
- Intentional type scale; pair a characterful display face with a calm body face.
- Restrained palette: one accent, one neutral family, tints only (no pure black/gray).
- Spacing is a system (4px base). Whitespace must earn its place.
- Components share one radius/border/shadow language.
- Real imagery over icons-in-circles. Show the actual product/context.

## Redesign existing projects
1. Audit current UI for generic/template tells. 2. Set design direction (DESIGN.md).
3. Fix hierarchy → typography → spacing → layout → responsive → consistency → a11y → micro-interaction → polish.
Preserve business logic, APIs, routes, database. Do not delete existing features.
